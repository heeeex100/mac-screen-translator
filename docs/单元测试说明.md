# 多多翻译单元测试

## 运行

在项目根目录执行 `swift test`。需要项目已有的 Xcode Command Line Tools 或 Xcode，不需要安装第三方测试框架。

只运行一组测试：

```bash
swift test --filter LearningNoteParserTests
swift test --filter ScreenshotGeometryTests
swift test --filter ShortcutFormatterTests
swift test --filter OCRTextFormatterTests
swift test --filter LearningNoteTaskTests
swift test --filter HotKeyRegistryTests
swift test --filter TranslationRequestTests
swift test --filter ImageInputTests
swift test --filter VisionModelTests
```

## 为测试做的代码调整

- 将原来的学习笔记解析和标签清理抽到 [LearningNoteParser.swift](../Sources/LearningNoteParser.swift)，服务调用完成后仍使用同样的解析规则和错误提示。
- 将截图选区的像素坐标计算抽到 [ScreenshotGeometry.swift](../Sources/ScreenshotGeometry.swift)，保留缩放、纵轴转换、整像素取整和边界裁剪规则，并拒绝无效的屏幕或图像尺寸。
- 新增 `OCRTextFormatter` 将布局排序与 Vision 分离；新增 `LearningNoteTask` 防止旧异步请求回写；新增 `HotKeyRegistry` 通过可注入注册回调验证冲突和失败回滚。
- 在 `Package.swift` 中加入 XCTest 测试 target，通过 `@testable import MacScreenTranslator` 调用内部逻辑。

异步和快捷键集成测试通过注入测试密钥、可控请求或注册回调实例化 `TranslationStore`，跳过钥匙串初始化。测试可能读取 AppStorage 的现有设置；空模型测试会临时修改模型设置并恢复原值。测试不访问钥匙串或用户剪贴板（图片测试使用独立临时剪贴板并清理），也不会发起真实网络请求、注册系统快捷键、截屏或启动 App。异步请求使用 continuation 控制完成顺序，并等待任务结束，不依赖延时碰运气。

真实 Vision 图片集成测试会加载系统识别模型，首次运行可能较慢，默认跳过；可显式执行：

```bash
MAC_TRANSLATOR_LIVE_OCR_TEST=1 swift test --filter ImageInputTests.testLocalVisionReadsGeneratedImage
```
